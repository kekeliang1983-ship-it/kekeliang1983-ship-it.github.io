# CozyCreatures · 治愈小生物 — 数值平衡表

> 用途：把全部「可调数值」集中成一张表，开发后台改数值时一处可查、一处可改。
> 设计原则：**外置 JSON 为真值源**（位于 `public/content/*.json`），后台改完即存、dev 热更立即生效；玩家进度由 store 死守 localStorage，不随配置覆盖。
> 标记说明：**已接入** = App 侧消费该系数；**联机后** = 桩已留、联机版本开启。

### 2.2 五行增益

- 风水主位加成 `fengshuiMainBonus = 0.12`，相生位 `fengshuiEngenderBonus = 0.06`，图鉴加成 `codexElementBonus = 0.05`。

## 十一、后台调参路径速查

| 想调什么 | 改哪个文件 / 字段 | 后台入口 |
|---|---|---|
| 法器增益系数 | `artifacts.json` → `artifacts[].effect` | 法器编辑器 |
| 作物产出/时长 | `farm.json` → `crops[]` | 灵田编辑器 |
| 风水/连击/天气 | `farm.json` → `fengshui* / combo / weathers` | 灵田编辑器 |
| 竞速倍率/奖励 | `race.json` → `events / rankRewards` | 竞速编辑器 |
| 签到奖励 | `checkin.json` → `days / milestones` | 签到编辑器 |
| 情绪瓶/漂流 | `bottle.json` → `bottle / drift` | 情绪瓶编辑器 |
| 神龛加成 | `shrine.json` → `incenses / deities` | 神龛编辑器 |
| 仙宠旅行 | `pet.json` → `travels[]` | 仙宠编辑器 |
| 天籁解锁 | `music.json` → `tracks[].unlockCost` | 天籁编辑器 |
| 画境定价 | `gallery.json` → `wallpapers[].price` | 画境编辑器 |

> 调参后：点「保存」即写回 `public/content/`（`dev` 热更立即生效）；可用「🔍 对比」看变更、「🕘 快照」一键回滚、「⬇️ 导出 / ⬆️ 导入」做备份迁移。
